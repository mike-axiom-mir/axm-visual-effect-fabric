# Holographic visibility v0.3

User device evidence showed the generic projector could preserve a form while still failing to communicate it: the recon-rover appeared as a small, very dim point cloud on a phone.

This pass changes only derived projection expression. Canonical form/sample identity stays unchanged.

The readable projector adds:

- deterministic sample-field bounds and viewport fit;
- density-aware point-size boost;
- stronger bounded exposure on sparse forms;
- mild depth-weighted brightness;
- two-pass glow/core point rendering;
- restrained breakup/motion rather than a descending scan bar;
- mobile-safe backing resolution and touch parallax;
- explicit visibility evidence in the realization.

The default three-form projector demo now uses this readable path. It remains a holographic projection, not a claim of photorealistic object rendering.
